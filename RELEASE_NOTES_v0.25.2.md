# AndAgent v0.25.2

## 中文

本版集中完善 Android 端 AI 助手的持续任务、设备能力与开源发布基础。

- LiveLoop 持续执行与分层记忆：核心记忆常驻、归档记忆按需检索，并提供管理入口。
- 定时任务创建、启停、查看与精确闹钟权限入口；相机浮窗和会话内相机卡片。
- NFC/MIFARE Classic 与 Ultralight 读写、OTG 外设、屏幕方向控制和 WAV 录音。
- 主题跟随系统、消息 token/耗时展示、网络搜索与网页读取、DevTools 调试入口。
- 中英双语基础 UI、关于页、三方组件声明、双语 README 和贡献指南。

## English

This release brings continuous agent work, stronger device integration, and open-source release polish.

- LiveLoop continuity and layered memory: persistent core memory, relevant archive retrieval, and memory management.
- Scheduled tasks with enable, pause, inspection, and exact-alarm permission controls; camera overlay and inline camera cards.
- NFC/MIFARE Classic and Ultralight read/write, OTG devices, orientation controls, and WAV recording.
- System-aware themes, per-message token and duration display, web search and page reading, and DevTools controls.
- Essential Chinese/English UI, About page, third-party notices, bilingual README, and contributor guidance.

The downloadable APK is built by the tag-triggered Release workflow and is debug-signed for direct installation.
